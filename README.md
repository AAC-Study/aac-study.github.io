# Учимся вместе — учебный сайт группы AAC

Сайт для однокурсников: уроки (иврит и русский), задачи с проверкой, личный кабинет, рамки и титулы по уровню, друзья, чаты и группы.

- Интерфейс: иврит, русский, английский; светлая и тёмная тема.
- Работает как обычный сайт на GitHub Pages, без установки.
- База и вход: Supabase (файлы в папке `supabase/`).
- Пока в `js/config.js` нет адреса базы, сайт работает в пробном режиме: всё хранится только в этом браузере, код приглашения `AAC2026`.

**Новая версия сайта.** Файлы сайта хранятся на устройстве (sw.js), поэтому при каждом изменении менять версию
в трёх местах одинаково: `version.json`, `SW_VERSION` в `sw.js` и `<meta name="app-version">` в `index.html`.
Новый файл, который подключает `index.html`, добавить в список `SHELL` в `sw.js` (проверяет `test/sw.e2e.js`).
