Настройка базы

Делается один раз. Нужно только администратору сайта.

1Код приглашения

Придумай код, который ты будешь давать одногруппникам. Без него никто не зарегистрируется. Минимум 6 символов.

Потом в Supabase: SQL Editor → New query → вставить → Run.

2Функция уведомлений

В Supabase: Edge Functions → Deploy a new function → Via Editor → стереть всё → вставить. Имя функции: push

3Красивые письма (по желанию)

В Supabase: Authentication → Emails → вкладка письма. В поле Subject вставить тему, в поле с текстом письма вставить письмо → Save.

На новых бесплатных проектах Supabase даёт менять письма только после подключения своей почты (SMTP).
